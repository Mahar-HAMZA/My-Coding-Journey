## 📌 Key Focus Areas

* **Clean & Modular Code**: Implementation of algorithms using industry-standard naming conventions and object-oriented principles.
* **Complexity Analysis**: Detailed Time ($\mathcal{O}$) and Space ($\mathcal{O}$) complexity evaluations for every solution.
* **Problem-Solving Mechanics**: Practicing core patterns across LeetCode and standard technical interview problems.

## 🗺️ Repository Map & Topics Covered

The codebase is structured logically to separate foundational data structures from core algorithmic paradigms:

| Category | Topics / Data Structures Implemented | Focus Areas |
| :--- | :--- | :--- |
| **Foundational** | Arrays (1D & 2D Matrices), Strings | In-place transformations, Two-Pointer, Sliding Window |
| **Linear Data Structures** | Linked Lists (Singly/Doubly), Stacks, Queues | Node manipulation, Memory allocation, LIFO/FIFO patterns |
| **Non-Linear Data Structures** | Binary Trees, Binary Search Trees (BST) | Tree traversals (DFS/BFS), Recursion, Structural logic |
| **Sorting Algorithms** | Merge Sort, Quick Sort, Bubble/Selection/Insertion | Divide & Conquer, In-place partitioning, Stability analysis |
| **Searching & Recursion** | Binary Search, Backtracking, Recursion Trees | Sub-problem reduction, Base conditions, State space search |
