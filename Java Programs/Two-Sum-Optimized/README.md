# Two Sum - Optimized HashMap Approach

This repository contains the highly optimized solution for the **"Two Sum"** DSA problem using a HashMap in Java.

## 📝 Problem Description
Given an array of integers `nums` and an integer `target`, return indices of the two numbers such that they add up to `target`.

## 🚀 Solution Approach
* **Logic:** Uses a **HashMap** to store the numbers and their corresponding indices. For each element, it calculates the complement (`target - nums[i]`). If the complement is already present in the map, we found the solution.
* **Time Complexity:** $O(n)$ — Single pass through the array, making it highly efficient.
* **Space Complexity:** $O(n)$ — Linear space used to store elements in the HashMap.
