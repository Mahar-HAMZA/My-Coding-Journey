# Queue Data Structure Arena ⏳

Step into the line! This folder documents my practical implementation of the **Queue** data structure, moving step-by-step through the rules of the **FIFO (First In, First Out)** processing logic.

### 🚀 Core Concepts Covered
* **Linear Queues:** Standard implementation handling sequential inputs.
* **Core Mechanisms:** Precise execution of `enqueue()` (insertion) and `dequeue()` (removal) operations.
* **Circular Queues:** Smart implementations designed to prevent memory overhead and optimize space utilization by reusing empty slots.
* **State Management:** Tracking underflow and overflow flags accurately.

### 🎯 Real-World Use Case
Queues are the backbone of printer job scheduling, CPU task scheduling, and handling asynchronous data streams (like network packets waiting to be processed).
