# Searching Algorithms Hub 🔍

Looking for a needle in a haystack? This space focuses on **Searching Algorithms**, implementing targeted logic to find and retrieve data points efficiently from a collection.

### 🚀 Algorithms Implemented
* **Linear Search:** The sequential approach that checks every individual element step-by-step ($O(n)$ time complexity).
* **Binary Search:** An optimized, divide-and-conquer strategy designed for **pre-sorted arrays** that slashes the search window in half at every single step ($O(\log n)$ time complexity).

### 💡 Core Rule
Always remember: while Linear Search is flexible and works on any messy layout, Binary Search requires strict, organized structure (sorted data) beforehand to work its magic!
