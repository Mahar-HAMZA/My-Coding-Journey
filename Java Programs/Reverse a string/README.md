# 🔤 Reverse a String

This repository contains the solution for reversing a string character by character in Java.

## 📝 Problem Description
Given a **string**, print all characters in **reverse order**.

## 💡 Example
- Input: "abcabcbb"
- Output: b b c b a c b a

## 🚀 Solution Approach
- **Logic:** Traverse the string from last index to first using a for loop and print each character
- **Time Complexity:** O(n) — Single loop traversal
- **Space Complexity:** O(1) — No extra space used
