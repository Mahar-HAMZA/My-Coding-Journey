# Binary Tree Hierarchical Lab 🌳

Moving beyond linear limits! This folder contains my implementations of **Binary Trees**, mapping out hierarchical, non-linear node relations where every structural point branches into a maximum of two paths.

### 🚀 Core Concepts Covered
* **Tree Architecture:** Designing node definitions containing data, left pointers, and right pointers.
* **Classic Traversals (DFS):**
    * **Pre-order:** (Root ➡️ Left ➡️ Right)
    * **In-order:** (Left ➡️ Root ➡️ Right)
    * **Post-order:** (Left ➡️ Right ➡️ Root)
* **Structural Analysis:** Calculating maximum height/depth of a tree, counting total nodes, and isolating leaf nodes.

### 🔍 Future Scope
Perfecting tree traversals paves the way for understanding advanced database indexing, routing tables, and building highly optimized search trees.
