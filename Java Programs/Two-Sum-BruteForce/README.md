# Two Sum - Brute Force Approach

This repository contains the Brute Force solution for the popular **"Two Sum"** DSA problem in Java.

## 📝 Problem Description
Given an array of integers `nums` and an integer `target`, return indices of the two numbers such that they add up to `target`.

## 🚀 Solution Approach
* **Logic:** Uses nested loops (`for` loops) to check every possible pair in the array to see if their sum matches the target.
* **Time Complexity:** $O(n^2)$ — Due to two nested loops iterating over the array.
* **Space Complexity:** $O(1)$ — Constant space used as no extra data structures are required.
