# 📊 Subarray Sum Equals K

This repository contains the optimized HashMap solution for the popular **"Subarray Sum Equals K"** DSA problem in Java.

## 📝 Problem Description
Given an integer array **nums** and an integer **k**, return the total number of **subarrays** whose sum equals **k**.

## 🚀 Solution Approach
- **Logic:** Uses **HashMap** with **Prefix Sum** technique to count subarrays in a single pass
- **Time Complexity:** O(n) — Single loop traversal using HashMap
- **Space Complexity:** O(n) — HashMap stores prefix sums
