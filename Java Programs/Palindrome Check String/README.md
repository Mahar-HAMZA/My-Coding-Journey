# 🔤 Palindrome Check String

This repository contains the solution for checking whether a string is a Palindrome or not in Java.

## 📝 Problem Description
Given a **string**, check whether it reads the same forwards and backwards.

## 💡 Example
- Input: "madam"
- Output: String is palindrome!

## 🚀 Solution Approach
- **Logic:** Uses **Two Pointer** technique — left pointer starts from beginning, right pointer from end, compare characters moving inward
- **Time Complexity:** O(n) — Single traversal
- **Space Complexity:** O(1) — No extra space used
