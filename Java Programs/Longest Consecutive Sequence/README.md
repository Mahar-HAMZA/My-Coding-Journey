# 🔢 Longest Consecutive Sequence

This repository contains the optimized HashSet solution for the popular "Longest Consecutive Sequence" DSA problem in Java.

## 📝 Problem Description
Given an unsorted integer array, find the length of the **longest consecutive sequence** of elements.

## 💡 Example
- Input: arr = [10, 5, 12, 3, 55, 30, 4, 11, 2]
- Output: 4  (sequence: 2, 3, 4, 5)

## 🚀 Solution Approach
- **Logic:** Uses **HashSet** to find sequence starting points and counts consecutive elements
- **Time Complexity:** O(n) — Each element visited at most twice
- **Space Complexity:** O(n) — HashSet stores all elements
